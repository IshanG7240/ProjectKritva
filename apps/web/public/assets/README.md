# Marketing Page Assets

Drop images here. They're served at `/assets/<filename>` in Next.js.

## Expected files

| File | Used in |
|---|---|
| `hero-bg.jpg` | HeroSection dark backdrop (optional overlay) |
| `og-image.jpg` | Open Graph / social share thumbnail (1200×630) |

Any image added here can be referenced in components as:
```tsx
<Image src="/assets/hero-bg.jpg" ... />
```
